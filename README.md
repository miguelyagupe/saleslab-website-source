# SalesLab website

> Portfolio source snapshot prepared on 20 November 2026 without earlier private commit history. The live website is deployed from the original development repository, not this snapshot.

This repository contains the static marketing website for SalesLab. It is separate from the signed-in application and Python API in `saleslab-api`.

- Website: https://saleslab.cc
- Application: https://app.saleslab.cc

The site introduces the product and links visitors to the application. Its published page is evidence of web design and deployment, not evidence that every financial feature described in marketing copy is available to every account.

As checked on 20 November 2026, the website returned HTTP 200. Vercel reported its latest production deployment as ready. The repository contains static HTML and small maintenance scripts; the application logic and tests belong to `saleslab-api`.
